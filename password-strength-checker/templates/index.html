    Proposed System and Working Principle

    From the moment a password is typed to the feedback shown on screen.

    1. 1

      User Input

      User enters the password via the web interface.

    2. 2

      Transmission

      The Flask backend receives the data through a JSON POST request.

    3. 3

      Processing

      Python extracts the numerical features from the password.

    4. 4

      Prediction

      The trained ML model analyses the features (model.pkl).

    5. 5

      Feedback

      The category and actionable suggestions are displayed.

    System advantages

    • Automated classification
    • Machine learning-based accuracy
    • Easy-to-use interface
    • Actionable security feedback
    • Modular architectural design

    Features extracted from each password

    Basic metrics

    Total length and counts of uppercase letters, lowercase letters, digits and symbols.

    Advanced metrics

    Shannon entropy (complexity), character-set size and total entropy in bits.

    Pattern analysis

    Repeated characters, sequences such as abc / 123, dictionary words, common passwords and leet-speak.

    Model Training and Evaluation

    Decision Tree, Random Forest and Logistic Regression were trained and compared. Every number below is loaded live from models/metrics.json, which is written by the training script.
